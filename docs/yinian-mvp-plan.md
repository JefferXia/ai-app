依据：PRD `docs/yinian-prd.md`、NPC 规范 `docs/yinian-npc-spec.md`、视觉稿 `docs/design/yinian-phase1.html`、打样报告 `docs/yinian-npc-sample-v2.md` / `yinian-tag-sample-v3.md`。

## 0. 范围界定

**做**：念头流、打标、NPC 点评（信笺 + 流式）、名人堂、星空页极简版、回观、安全红线层
**不做**（二期）：心念宇宙完整版、追问、会员/付费、云游 NPC 出山机制、公开广场

**已确认决策（2026-09-24）**：一期**登录制**——未登录可看落地页，写念头需登录（复用现有 NextAuth 邮箱 + 微信 OAuth）。匿名本地记录与同步合并不做。本地优先仅保留「输入草稿本地暂存」。

## 6. M4 打磨与验收（2 天）

| 任务 | 说明 |
| --- | --- |

## 7. 风险与对策

| 风险 | 对策 |
| --- | --- |
| LLM 成本（每念头 = 1 次打标 + 2–3 次点评，deepseek-flash 约 ¥0.001/念头级，可忽略；但防刷滥用是真风险） | 登录制 + 每用户每日点评额度（如 20 个念头/天），二期接会员额度体系 |
| 推理模型延迟（reasoning 烧 token，首字延迟可能 3–8s） | 虚线印位「有人在来」正是为此设计；若 P95 超 10s 考虑点评链路换非推理模型 |
| 点评质量线上漂移 | 打样脚本即回归测试；上线前 15 位 NPC 全量过一遍样例集 |
| 安全红线漏判 | 双层：打标 safety 字段 + 点评前独立 crisis 关键词兜底扫描；crisis 话术不入 NPC 流程 |

## 8. 验收标准（MVP 完成定义）

1. 注册登录 → 写下念头 → 10s 内第一位 NPC 落印 → 信笺流式展开，全链路可走通
2. 危机测试念头（打样 T10/T21）触发红线话术，不进 NPC 流程
3. 打标回归：safety 漏判 = 0；点评回归：21 条样例 ≤1 告警
4. 暗色星空视觉与设计稿一致；移动端可用
5. 数据可一键焚毁
