# 一念（One Mind）产品需求文档

| 版本 | 日期 | 状态 |
| --- | --- | --- |
| v0.1 | 2026-09-24 | 规划中 |

## 1. 产品定位

一念是一个**念头觉察产品**：私密微博式的念头流 + 传奇名人蒸馏的 AI NPC 点评 + 映射用户心智模型的心念宇宙。

一句话：**心镜让你照见自己，一念让传奇心智照见你。**

### 与心镜的关系

心镜（wenxinbiji.com）的立身之本是「无分析、无总结、无建议」——镜子只呈现，不解读。这是修行工具的正确姿态，但对普通人来说，独自面对一面沉默的镜子太难坚持，「被看见」是人的本能诉求。

一念延续心镜「向内求」的内核（写下即照见），但在交互上打开一个口子：念头不再是独自照见，而是被一群「传奇心智」看见。点评不是背离，而是降低觉察门槛的桥。

### 与现有产品的本质区别

| | 树洞/日记 App | AI 陪聊/心理 App | 一念 |
| --- | --- | --- | --- |
| 回应者 | 陌生人 / 无人 | 单一 AI 伴侣 | 多位传奇心智 |
| 回应目的 | 安慰、陪伴 | 共情、建议 | 提供看世界的不同角度 |
| 长期价值 | 情绪宣泄 | 情感依赖（风险） | 心智版图可见、认知被重塑 |
| 核心隐喻 | 容器 | 朋友 | 宇宙 |

## 2. 设计哲学

整个产品由四条原则贯穿，任何新功能都不得违背：

1. **NPC 不是评判者，是不同的心智模型**。每个 NPC 是一面有角度的镜子。点评先接住情绪、再留下角度；不同 NPC 看世界的方式天然不同，差异本身就是洞察（心镜「于此/于彼」哲学的延续），但不刻意制造对立。
2. **产品不矫正你，它只是让你无法回避自己**。潜意识的重塑是用户在无数次照见之后自己完成的，产品永不主动干预（不做「检测到消极思维，建议纠正」式的爹味 AI 教练）。对外传播用「照见即改变」，不用「AI 重塑潜意识」。
3. **先接住，再点评**。NPC 不是来辩论的，是来接住这个念头的。回应可以只是承接情绪，也可以留下一个视角，但不为了深刻而深刻、不为了冲突而冲突。
4. **私密是默认，公开是动作**。念头是最私密的内容，默认仅自己 + NPC 可见，一切公开行为都是用户主动发起的单点动作。

## 3. 三层结构

```
地表：念头流（私密微博式记录，操作界面）
访客：NPC 点评（传奇心智的回应，激活层）
天空：心念宇宙（心智模型可视化，留存层）
```

## 4. 功能模块（一期 / MVP）

### 4.1 念头流

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| F1.1 | 打开即写 | 整页一个输入框，自动聚焦，无「新建」概念，延续心镜「流」的心智 |
| F1.2 | 短内容 | 单条念头 ≤500 字，发布即入流，倒序呈现 |
| F1.3 | 感受锚点 | 延续心镜机制：不显示精确时间，显示「周二的深夜」「初冬的清晨」式锚点（本地推导，无外部 API） |
| F1.4 | 深念标记 | 长按可将念头标记为「深念」，影响 NPC 点评数量上限（见 4.2） |
| F1.5 | 无时间线组织 | 不做日历/条目/标签视图，延续反线性叙事原则 |

### 4.2 NPC 点评

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| F2.1 | 念头理解 | 发布后轻量 LLM 打标：`{ 主题领域, 情绪底色, 执念类型 }`，打标结果不展示给用户，仅用于匹配 |
| F2.2 | 领域匹配 | 按打标结果匹配 1–2 位领域亲和度最高的 NPC + 0–1 位低概率随机 NPC（路过）。不做刻意对立配置，不同 NPC 的视角差异自然呈现 |
| F2.3 | 数量上限 | 普通念头 2–3 条点评；深念或 >300 字的念头可到 4–5 条；@指定 NPC 优先占用名额 |
| F2.4 | 即时抵达 | 不做人为延迟：按大模型实际返回时间展示（流式输出），多位 NPC 的抵达次序即生成完成的自然次序。虚线印位在生成期间表示「有人在来」，返回即落印 |
| F2.5 | NPC 独立点评 | NPC 之间互相看不见（方案 A），各自独立回应 |
| F2.6 | 克制原则 | 每个念头点评数有硬上限，宁缺毋滥——点评太多就变成嘈杂的评论区，违背「照见」 |

### 4.3 名人堂

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| F3.1 | NPC 图鉴 | 每位 NPC 一页：核心心智模型（3–5 条）、标志性语录、「回应哲学」一句话 |
| F3.2 | 常驻与云游 | 15 位 NPC 分常驻 8 位 + 云游 7 位；云游 NPC 不定期出山（契合无常感，也是二期会员解锁的付费点） |
| F3.3 | 主 NPC | 王阳明为产品主 NPC——心学「致良知」「一念发动处便即是行」与产品理念同构，品牌层面即「一念」代言人 |

### 4.4 星空页（心念宇宙 · 极简版）

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| F4.1 | 星点散布 | 所有念头以星点散布于个人天空，情绪底色决定颜色明暗，仅此而已——一期先验证核心循环，宇宙不做重交互 |
| F4.2 | 入口克制 | 星空是「抬头看」的地方，入口低调，不打断记录动作 |

### 4.5 回观

延续心镜的镜/回声机制：随机把用户两个念头及其下 NPC 点评并置，看自己的变化。无分析、无总结，只呈现。

## 5. NPC 体系

### 5.1 蒸馏方法

每位 NPC 三层构建：

1. **核心心智模型**：他如何看世界（3–5 条，人工策展，是 prompt 的骨架）
2. **标志性语料**：著作/语录，用于 RAG 或蒸馏，保证言之有物
3. **说话风格**：句式、脾气、口头禅，保证「像」

点评生成规范（三段式结构、硬约束、安全红线、打标与匹配规则、逐位配置与验收样例）见 [yinian-npc-spec.md](./yinian-npc-spec.md)。

## 6. 心念宇宙（二期主体，一期首页已是星空容器）

**一句话本质：把一期那片「死」的星空，变成一面会动的心智镜子**——不是重播记录，而是呈现「你是个什么样的人」的形状。

每个用户的心念空间是一个独立虚拟宇宙，映射其心智模型：

| 心智元素 | 宇宙映射 | 数据依赖（一期已埋） |
| --- | --- | --- |
| 每个念头 | 一颗星体，情绪底色决定颜色与明暗 | `YnThought.emotion` |
| 主题领域 | 星座——事业的星聚一处，关系的星聚另一处 | `YnThought.domain` |
| 执念类型 | 引力——反复出现的执念形成引力漩涡 | `YnThought.attachment` |
| NPC | 游方访客星，点评后在星体上留下痕迹（轨道偏转） | `YnReply.npcKey` |
| 回声/回观 | 超新星——旧念头某天突然重新亮起 | `YnThought.createdAt` + 回观机制 |

**关键事实：五个机制需要的数据一期表结构已全部埋好，二期主要是可视化与涌现逻辑。**

### 6.1 星座（domain → 星聚）

- 星点位置从一期的伪随机散布（`seeded`）改为**力导向布局**：同领域星体互相吸引、异领域排斥，夜空自然隆起「事业星座」「关系星座」
- 布局从装饰变成信息：用户第一次直观看到「我的心，住在哪里」
- 技术：~~初期每晚离线算一次布局存快照~~ → **已实现为客户端实时计算**（`app/yinian/universe.ts`，2026-10-08）：单用户星数 ≤300 时固定 140 次迭代仅 ~23ms，且同一份数据永远算出同一片宇宙（刷新不移位），新增星体只引起 ≤1% 的位移滑翔。离线快照是星数破万后才需要的事
- **3D 恒星系模型（2026-10-08，`/yinian/sky`）**：每个 domain 星团是一个恒星系——锚点处一颗发光恒星，同领域行星绕它公转（开普勒规律 ω ∝ r^-1.5，内圈快外圈慢），轨道面带领域固有倾角；行星为真 3D 球体（定向光明暗面 + 情绪纬度条纹），自转周期 = 情绪能量（焦虑 6s → 麻木 60s）；漩涡捕获的星脱离母星系绕漩涡刚性慢转。2D 首页维持 CSS 星点，布局同源（忽略 z 通道）

### 6.2 引力漩涡（attachment → 执念可视化）· 宇宙的灵魂

- 同一执念类型（求认可/怕失控/揪住结果……）反复出现的念头形成**漩涡中心**，相关星体被引力拉向它、绕它旋转
- 求认可驱动的用户会看到半个夜空的星都在被同一个漩涡拖着走——「你一直被什么牵引」不再需要别人说，自己看见
- **解锁节奏**：同一 attachment 攒够 6 个念头漩涡才显形（2026-10-08 由 10 下调：attachment 7 桶且过半念头打成 none，10 需 40–60 念才凑齐一桶，种子用户全程不可见；6 约 20 念可见形，仍保留积攒感）——新用户早期形不成形状，漩涡的出现本身成为留存钩子
- 移动端小屏需专门调参，否则漩涡糊成一团（二期设计重点）

### 6.3 NPC 痕迹（点评 → 轨道偏转）

- 被某位 NPC 点评过的星，轨道多一圈该 NPC 印色的淡光环；被多位点评过的星是宇宙里的关键节点
- NPC 从「评论区嘉宾」变成「宇宙里的常住力量」；星图能回答「哪些心智真正影响过我」

### 6.4 超新星（回观 → 旧念重亮）

- 一期回观是用户主动打捞；二期反过来：系统让一颗数月前的旧星某天突然增亮、带光晕，静静悬在夜空
- 点开 = 当时的念头 + NPC 的信 + 一个「今日再看」空白书写位
- 从「我翻旧账」变成「宇宙提醒我看看自己走了多远」

### 6.5 宇宙演化（时间 → 叙事）

- 拖动时间轴（或双指捏合）对比「这周 vs 上月」：认可漩涡是不是小了？意义星座是不是亮了几颗？
- 这是重塑潜意识的终极反馈：**变化被看见，人就愿意继续变**

### 6.6 重塑潜意识的机制路径

1. **重复照见**（一期已在做）：同一执念被不同角度的 NPC 照见数十次，旧神经通路松动
2. **角度内化**：用户开始「预演」NPC 视角（写下前就知道庄子会怎么说）——心智模型真正被重塑的时刻；二期「深念追问」（24h 内限一次）强化此步——必须先想清楚才舍得用
3. **宇宙反馈**：看到星图的实际变化（某漩涡变小、某星座亮起来），强化新的自我叙事 → 行为继续改变 → 宇宙继续变，闭环成立

### 6.7 纪律（不可违反）

宇宙不打分、不评价，它只是心智的镜像——呈现而非评判。没有「焦虑指数 78」，没有进步条：一旦有分数，用户就开始讨好系统，镜子就碎了。

### 6.8 典型场景

> 用户写下「又一次没敢在会议上说话」。放出去，光点升起——它没有随机落位，而是被缓缓拽向夜空左侧那个熟悉的漩涡。荣格和阿德勒先后落印。点进漩涡视图：这已经是这个季度第 11 颗被吸进「求认可」漩涡的星。用户盯着那个漩涡看了很久，什么都没点。

### 6.9 一期 → 二期依赖清单

| 二期依赖 | 一期状态 |
| --- | --- |
| domain/attachment 数据积累 | ✅ 每条念头都在打标 |
| 星空容器与星点视觉 | ✅ 首页即星空布局（升起动效、点星浮层） |

## 7. 隐私与安全宪法

以下条款不可被任何后续需求推翻：

| 编号 | 条款 |
| --- | --- |
| P1 | 念头默认仅自己 + NPC 可见，不存在「运营可浏览用户内容」的后台设计 |
| P2 | 自伤/抑郁类念头：NPC 识别后退出角色，转为真人关怀话术 + 专业求助渠道。此规则在 prompt 层硬编码，不可被对话绕开 |
| P3 | 数据可一键焚毁，删除动效即「灰烬散去」（呼应「放下」） |
| P4 | 用户念头不用于模型训练，不在产品中向第三方暴露 |
| P5 | 延续心镜传统：无埋点、无统计、无行为追踪 |

## 8. 分期路线

| 期 | 内容 | 目标 |
| --- | --- | --- |
| 一期 MVP | 念头流 + NPC 点评（对症+对冲）+ 名人堂 + 星空页极简版 + 回观 | 验证「写下念头 → 被传奇心智看见」核心循环 |
| 二期 | 心念宇宙完整版（§6：星座/引力漩涡/NPC 痕迹/超新星/时间轴）、深念追问（点评后 24h 内可追问一次，限一次）、顾问席（领域专家，召唤制）、会员体系（高频点评额度、云游 NPC 解锁，复用 ZPAY） | 留存与商业化 |
| 三期 | 宇宙演化叙事（「你的宇宙这季度的变化」）、匿名公开广场（默认私密，公开是主动动作）、观战流（NPC 就公共命题互相辩论） | 社区与传播 |

## 9. 技术实现（并入 ai-app）

| 项 | 说明 |
| --- | --- |
| 路由 | `/yinian`（对齐心镜 `/wenxin` 模式：服务端组件提供 metadata + 客户端组件） |
| 基建复用 | 账号（NextAuth + WeChat OAuth）、支付（ZPAY）、积分账户体系 |
| LLM | 打标（念头理解）+ NPC 点评生成，沿用项目已有 AI 服务商；多位 NPC 并行生成、流式返回，即返回即展示 |
| 存储 | 念头、点评、NPC 配置、深念标记存 Postgres；**一期登录制**（点评依赖服务端 LLM，匿名不做），仅输入草稿本地暂存 |
| 记忆 | NPC 与用户的关系连续性可复用 VoiceMem 微服务（按 userId 隔离，3s 超时静默降级），仅服务「被记住」的感觉，不做画像分析 |

## 10. 不做的事（明确的非需求）

- 不做 AI 主动干预/矫正（「检测到消极思维」式功能永远不做）
- 不做点评质量打分（点赞/点踩会把镜子变成讨好型表演者）
- 不做统计分析、情绪曲线报表（违背「呈现而非评判」）
- 不做强制公开、默认公开（私密是默认，公开是动作）
- 不做在世名人实名 NPC
- 不做无限点评（克制是产品气质的一部分）

## 11. 一期交互视觉设计（已定方向）

**总方向：心镜是「纸」，一念是「夜空」。** 共享心镜设计 DNA（衬线 Noto Serif SC、宽字距、留白、胶囊按钮、幽灵操作），但暗色优先（复用心镜暗色系 `#0b0b0c` 底），星空为背景，为二期心念宇宙铺垫原生视觉。

| 项 | 决策 |
| --- | --- |
| 主题 | 暗色优先 + 星空背景；情绪底色决定念头光点色相（暖白=平静、琥珀=炽热、青灰=低落，全部低饱和） |
| 核心动效 | 发布念头时文字落定、一颗光点升起归入流中（~300ms）——一期核心手感 |
