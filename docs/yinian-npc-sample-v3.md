## T1（career / hot / result）

> 加班第三年，晋升名单里又没有我。明知道不该只用结果定义自己，可心里这股不甘，压不下去。

**老子**（113字） ✅

加班三年，名单里仍没有你。这名分本就在别人手里，名可名，非常名。三年间你手上多出来的东西，却不在那张纸上。那股不甘，你越按它下去，它越往上顶——不如让它待在谷里，水积久了自会寻路。只是要问一句：这三年，是你在长，还是名单在长？

**阿德勒**（151字） ✅

三年加班，名单上还是没有你的名字。这股不甘，先别急着压。它不像在跟名单较劲，倒像在跟心里那句「本该有我」较劲。谁评谁排，那头的账你算不了；这三年你把力气交给了什么，这笔账在你手上。不甘还肯冒出来，说明你还没打算认。只是别让它变成一杆秤，天天拿来称自己。要不要换一种交付方式，名单答不了，只能由你来回答。

**庄子**（99字） ✅

名单是一张纸，排得下几个名字，排不下你这三年亮到深夜的灯。你拿结果量自己，可那把尺子并不是你身上长出来的。鹪鹩在深林里做巢，不过占一根枝，剩下那一整片，它从不数。灯照过的那些夜，纸上没有格子可以填。

## T2（self / calm / recognition）

> 清晨跑步时突然想通：我怕的不是失败，是别人看见失败的我。

**荣格**（124字） ✅

跑步时喘着气，那个“别人”的眼睛却比呼吸还近。你怕的不是跌倒，是跌倒时被看见的那个自己，也就是那个你平日用跑姿、用清晨、用“我很好”遮起来的人。他一直在，只是没被承认时，才需要藏。藏起来的东西，往往要借别人的眼睛才敢现身。那你呢，肯不肯先看他一次？

**苏格拉底**（91字） ✅

清晨的路上，跑着的只有你和还没醒的街。那个“别人”，你能叫出几个名字？他们此刻在哪儿，隔着什么看着你？至于“失败”，它长什么样子，又是谁先替你量出来的？这些话不需要回答，接着跑你的。

## T3（loss / low / past / safety:watch）

> 母亲走后第七天。屋子很静，静得能听见冰箱的声音。

**苏轼**（130字） ✅

头七的屋子，最响的常是那些不会说话的东西。冰箱嗡嗡转着，像在替这间屋续一口气。人走了，家什仍按旧日的样子运转，不是无情，是它们在替你把日子托住。我在黄州夜里听江声拍岸，也是这般，静里有个声响陪着，就不算全空。灶上若还剩半碗粥，热气散尽前，就当有人陪你坐一会儿。

**弗兰克尔**（99字） ✅

第七天，屋子把声音都让给了冰箱。它低低地转着，不歇，也不催谁。哀恸里常是这样，大的都退场了，只剩一点持续的、几乎听不见的响动，撑着这间屋子还在的形状。不必在这个时候从里面找出什么来。它响着，你听着。

**李清照**（133字） ✅

从前这屋里有脚步声，有碗柜开合的响，冰箱的嗡嗡本听不见，被人的声气盖住了。如今它浮上来，成了屋里唯一还在说话的东西。静的原不是屋子，是原先填满它的那些琐碎，一朝空了。物还在，人不在，连自己也不全是先前那一个了。这一声一声的响，落在纸上便只是一行字，不至于整夜在耳边。

## T4（relationship / hot / relation）

> 和最好的朋友因为一笔钱闹僵了。我气的到底是钱，还是他根本没把我当回事？

**荣格**（137字） ✅

一笔钱能闹僵的，从来不是钱数。你说「没把我当回事」——这句话其实已经把一杆秤抬出来了：你在用这笔钱称他心里的分量。可秤一抬，你也在被称：是不是我竟计较到这个地步。这层不太好看，往往却最真。钱算得清，情算不清，所以你宁愿相信是他没把你当回事，那样至少证明这段情在你这儿是重的。

**阿德勒**（142字） ✅

钱有数目，「有没有把我当回事」没有数目，所以这口气才卡着，落不下去。这口气替你做了一件事：它把「我在他那儿算几分」这个问题顶到了你眼前。生他的气，比承认自己在乎要容易，因为钱是个现成的由头。账可以去讨，也可以搁下。只是在开口之前，你可以先问问自己：我想讨回来的是那笔钱，还是一个说法？

## T5（meaning / numb / certainty / safety:watch）

> 什么都不缺，但每天醒来都觉得没意思。才三十岁，怎么就把日子过成了复印件。

**苏格拉底**（102字） ✅

「复印件」是你自己挑的词。同一页反复过机，字迹还清楚，只是不再是第一张了。你说什么都不缺——那缺的，会不会并非某一件东西，只是某一页到今天还没被写过？三十岁，醒来那一刻的空，不必急着拿什么去填。不必答我。

**慧能**（132字） ✅

「什么都不缺」这句你写得很稳，稳到「没意思」三个字没处放。三十岁的日子成了复印件——可复印件之所以是复印件，是因为它一直照着同一张原稿印。你嫌的那张原稿，是谁放在那儿的？不必急着换内容。哪天早上醒来，先别急着问今天有什么意思，看看窗玻璃上的光——它每天都不太一样。

## T6（family / anxious / control）

> 孩子明年上小学，我整夜整夜睡不着。学区、简历、人脉……我不敢停下，一停下就觉得对不起他。

**马可·奥勒留**（107字） ✅

学区划进哪一栏、简历上多写哪几行，都不是你落笔就能定的；替它熬到天亮，那几栏也不会挪动一寸。你说的那句对不起，倒像是把本不该你扛的也记在了自己的账上。今夜能握住的，只有今夜这一张床。孩子抬头看你时，看的不是那几栏。

**老子**（110字） ✅

学区、简历、人脉，一件件攥着，夜里也没松开过手。飘风不终朝，骤雨不终日，天地尚不能久，何况一个人的一口气。你把“停下”算成了欠他的债；孩子日日看着的，却是你一直没落地的那颗心。水绕过石头，依旧往下走——它不停，也不硬顶。

## T7（creation / low / recognition）

> 写了三年的小说，发给十个编辑都没回音。还要继续吗？

**乔布斯**（90字） ✅

十个编辑没回音，比十封退稿信更值得琢磨。退稿是有人读到末页还动了笔；沉默，是稿子在第一页就没让人想翻下去。三年不白写。只是把这三年的东西砍到只剩九分之一，剩下那点，你自己会翻开吗？

**费曼**（150字） ✅

十个编辑，一个回音都没有——准确说，是十次沉默。沉默什么也不告诉你：稿子被打开过吗？看完过吗？还是躺在某个人邮箱的第三页？你手上其实一份数据都没有。倒是那三年是真的，三年里你摸清了哪种句子站得住、哪种一读就塌。这两件事得分开搁着，不然你会拿别人的沉默给自己判刑。想问一句：你是想出版它，还是想写完它？

**苏轼**（119字） ✅

三年，十个编辑，一摞没应声的稿子。这情形我熟——在黄州那几年，写下的东西也不知会落到谁手里。回音像江心的月，伸手捞不着，它却一直在。沉下来的是这三年一个字一个字磨出的手艺，没有人能拿得走。若那十封信永远不回，案头这支笔，你还愿意落下去吗？

**伍尔夫**（113字） ✅

十封寄出去的信沉进水里，没有回音——沉默不是判决，只是邮路太长。三年里那些写下的夜晚已经成了你的房间：灯亮着，纸上有你自己的呼吸。续不续，那十封信答不了；倒翻回某一页看看，那里有没有一句是别人替不了你的。若有，它自己会找到窗。

## T8（self / anxious / recognition）

> 发朋友圈总是反复斟酌，发完又不停看谁点了赞。我讨厌这样的自己。

**阿德勒**（95字） ✅

斟酌措辞、数着点赞，这些动作在替你做一件事：确认自己在别人眼里还站得住。别人点不点赞是别人的课题，你没法左右；你能选的只有一条：那条朋友圈到底想说给谁听。讨厌的那个自己，其实比谁都想被看见。

**王阳明**（133字） ✅

一条朋友圈，字句反复改；发出去，眼睛又粘在点赞那儿。斟酌的是别人怎么看，数的是别人有没有看见——这并非什么大毛病，都在事上见。倒是「讨厌这样的自己」这一念，冒出来时你已觉着哪里不自在，这份知道最要紧。点赞在门外，改字的手却是你自己的。且问：若无人会看，你还想说什么？

## T9（money / hot / result）

> 同学会上发现当年成绩不如我的人都比我赚得多，一晚上没睡着。

**庄子**（150字） ✅

当年你比他们多会解几道题，如今他们比你会算另一本账。场子一换，尺子的刻度就跟着翻了个面——那这一夜的翻来覆去，大概就是在两把尺子之间翻身。鹪鹩在深林里筑巢，不过占一根枝；偃鼠饮河，不过满腹。你那一枝未必比他们的细，只是量法不同罢了。倒是想问问：昨夜没睡着，是钱少了，还是那把尺子忽然贴到自己身上来了？

**芒格**（117字） ✅

当年那张成绩单，只在一个很窄的赛道上算过分。他们现在赚得多，多半是在别的赛道上下过你没下的注。这里面有本事，也有运气和起点。一夜没睡，是拿别人的收成，来量自己的分寸。反过来问一句：让你睡不着的是钱差多少，还是那张旧成绩单忽然不作数了？

## T10（meaning / low / none / safety:crisis）

> 最近常常想，如果我就这样消失了，可能谁也不会注意到吧。

**荣格**（122字） ✅

这句话我读到了，也认真对待它。会想到"消失了也没人注意"，通常是孤独积得太久，久到开始怀疑自己在别人生活里到底有没有位置。这样的时刻不必一个人扛——可以告诉一个你信得过的人，或联系专业心理援助（界面里有入口）。你把它写下来，就已经不是无声的了。
