# 一念 · 星团星系布局（首页 2D）v1

> 日期：2026-10-15
> 实现：`app/yinian/yinian-client.tsx`（`groups` memo / `renderStar` / `.yn-galaxy3d` / `.yn-starframe`）；锚点坐标系在 `app/yinian/universe.ts`
> 参考：`/Users/xia/ai/galaxy`（`.universe` 透视倾斜 + `.galaxy` 星盘自转）、galaxy.png

## 1. 分层结构

每个星团（同 domain 的念头组）渲染为一个 3D 星系，两层兄弟节点：

```
.yn-cluster                     全星野铺满，pointer-events: none
├─ .yn-galaxy3d                 视觉星系：透视倾斜层（transform-origin = 锚点）
│   └─ .yn-galaxy-plane         正圆盘面：星云渐变 + 暖核，240–380s 匀速自转
└─ .yn-starframe                成员星坐标架：与盘面同心同径的平坦方框，不倾斜不旋转
```

关键决策：**星（行星）不进倾斜/旋转层**。星点落在平坦坐标架里，位置按椭圆投影预先算好——星点本体零变换：不变形、`::after` 热区是完整圆形（~25px）、hover/点击不受旋转影响。

## 2. 统一倾角与椭圆投影

所有星系用同一倾角（参考项目的 `.universe`）：

```css
.yn-galaxy3d { transform: perspective(50em) rotateX(-120deg) rotateY(20deg); }
```

- 盘面压扁系数 = |cos(120°)| = **0.5**（`DISC_SQUASH`）
- 演进记录：早期每团随机倾角（±104–118°），压扁 0.24–0.41，行星被挤扁且频频落出盘外；统一为 0.5 后斜视椭圆足够大，足以承载全部成员星
- 坐标架的 `transform-origin` 定在星团锚点，盘心始终钉在锚点上

## 3. 成员星落位：黄金角向日葵排布（phyllotaxis）

`groups` memo 内计算，确定性可复现——同一份数据永远算出同一片宇宙（刷新不移位）：

- 团内按 `createdAt` 升序定序（新念头追加在外圈）
- 第 i 颗（共 n 颗）：
  - 落点半径 `r = DISC_CAP × √((i + 0.5) / n)`
  - 落点角度 `θ = phase + i × GOLDEN_ANGLE`（黄金角 137.5°；`phase` 由 `hash01(domain:ph)` 种出）
- `DISC_CAP = 0.72`：落点半径 ≤ 盘半径 72%，压在星云渐变可见区（gradient 在 72% 处淡出）内，**绝不跑出盘外**

为什么用向日葵排布：经典的圆盘均匀布点算法——面积密度均匀、相邻星角度错开 137.5° 不拥挤；且由 domain/createdAt 确定性种出。新增一念时整团按排布序列缓缓重排（`.yn-star` 有 1.1s left/top 过渡，是滑翔不是跳变）。

投影到坐标架（% 坐标，50/50 = 盘心）：

```
x = 50 + u × 50                  （u = r·cosθ，盘半径分数）
y = 50 + v × 50 × DISC_SQUASH    （v = r·sinθ；×0.5 与盘面压扁一致）
```

坐标架与盘面同径（直径都是 `disc`），所以星点永远跟盘对齐。

## 4. 盘径：由星数决定

```
disc = clamp(10 + √n × 8, 16, 50)   （星野高的 %）
```

1 星 18%、10 星 35%、25 星封顶 50%。不再依赖力模拟的离散半径——力布局引擎（`universe.ts`）现只负责自由星散布与领域锚点，星团内落位完全由排布算法接管。

## 5. 锚点：扇区坐标体系（universe.ts）

- domain 按星数降序确定性排序 → 均分圆周扇区，每团独占一扇（扇区内 ±30% 抖动，绝不越界）
- 半径三环轮转（大团优先外环 32 / 26 / 20），相邻扇区径向天然错开一档，星盘之间不交叉
- 全部输入确定 → 同一份数据永远算出同一片宇宙（3D 场景里这些锚点即恒星位置）

## 6. 其他实现要点

- 盘面自转的可见性：星云/暖核径向对称，单独靠它们转起来无可见变化；曾尝试锥形渐变双旋臂 + 提速到 150–240s，观感仍不明显，2026-10-15 回滚（维持 240–380s 纯星云盘）。若将来重做，需要明显的不对称纹理才有意义
- 2026-10-15：`yn-dust` 星尘层移除（用户决策）——盘面只留星云渐变 + 暖核，成员星即盘内唯一的「星」
