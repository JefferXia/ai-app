# 一念 · 星体视觉方案 v0.1

> 依据：UC Berkeley（Cowen & Keltner, PNAS 2017）27 类情绪研究；一期打标维持 5 底色。
> **2026-10-15**：按霍金斯意识层级（Map of Consciousness）校准为 7 档能量层级（见 §3），
> 新增 courage / love 两档，颜色沿霍金斯图表色带重排；伯克利 27 类仍是 §4 的远期扩展预留。
> **2026-10-16**：行星去星环、去纹理带与明暗层，样式**严格参考**经典太阳系 CSS——
> 渐变方向与 box-shadow 逐档照搬参考值（numb 的 inset 月牙、sun 的双层金光、Jupiter 的
> 橙乳横纹等）；星体原型更名为黑矮星 / 深海蓝星 / 木星 / 赤矮星 / 熔金太阳 / 月球 / 天王星。
> 实现：`app/yinian/yinian-shared.tsx`（`STAR_VISUAL` / `Planet` / `STAR_CSS`）

## 1. 设计判断

伯克利研究表明人类体验到的情绪网络细分可达 27 种相互交织的状态。但一期**打标层不扩展到 27 类**：

- 5 底色打标准确率 84–88%（已回归验证）；27 类会大幅掉准确率
- 用户对自己的情绪有真值——星体视觉「错了」（悲伤的念头显示成欢愉的星）会立刻破坏信任
- 情绪字段误判的容错原则是「优雅降级」，但视觉是用户直接感知的，不是后端字段

因此方案分两层：**打标维持 5 底色；视觉层建立完整语法**，27 类每种都能用语法组合表达。未来打标扩展到细腻情绪（如 12–16 类）并重新建立回归基线后，视觉方案零改造接入。

## 2. 视觉语法（三通道）

每颗星 = **色相族 × 能量 × 质感** 的组合：

| 通道 | 对应心理维度 | 视觉载体 |
| --- | --- | --- |
| 色相族 | valence（效价：积极/消极） | 主色温与色相 |
| 能量 | arousal（唤醒度） | 光晕强度、脉动节奏、内核亮度 |
| 质感 | 情绪的具体质地 | 表面多层渐变（明暗面）、运动形态 |

两个尺度同源：

- **星点**（星野中，5–8px）：单色渐变 + 双层光晕 + 脉动
- **星球**（点击星点 → **在星的位置原地放大** ~150px，非浮层内嵌）：样式**严格参考**经典太阳系 CSS——线性渐变球面 + 按档位 box-shadow（numb 的 inset 月牙、sun 的双层金光、Jupiter 的橙乳横纹、uranus 的青白辉光），无纹理带/明暗层，静态无自转（自转通道由 sky 3D 行星承载）+ 0.55s 缩放回原位入场；信笺点评仍在底部浮层

自转周期即唤醒度（sky 页 3D 行星的自转；2D 星点以脉动/闪烁动画承载同一通道）：anxious 6s（急促）→ hot 9s → courage 12s → calm 26s → low 34s → love 44s → numb 60s（近乎停滞）。
亮度（自发光/光晕强度）即霍金斯层级，沿量表单调上升——爱最亮，愤怒响而不亮（响度走转速/闪烁通道）。

## 2.1 为什么不用 Three.js（一期决策）

点击旋转放大的动效用纯 CSS（遮罩 + 纹理平移 + 明暗覆盖）即可达到足够好的球体自转观感，而 Three.js 引入 ~600KB bundle、移动端功耗与 React 状态同步成本，对一期是杀鸡用牛刀。**Three.js 的正确时机是二期心念宇宙**：星座力导向布局、引力漩涡、相机推拉等连续空间变换出现时再迁移——届时本方案的色相/光晕/纹理参数可直接映射为着色器 uniform，视觉零返工。

> **2026-10-08 已迁移（/yinian/sky）**：3D 场景落地（`app/yinian/sky/universe-scene.tsx`，three + @react-three/fiber + drei，`next/dynamic` 仅本页加载，sky 页全屏、页内无 header）。映射关系：星点 = 径向渐变精灵（共享白色纹理 × 情绪色，加法混合）；能量通道 = 精灵缩放脉动/透明度呼吸与闪烁（单 `useFrame` 驱动全部星点）；漩涡 = 暗核球 + 双臂对数螺旋粒子带缓转，螺旋臂 z 起伏由布局引擎输出；NPC 痕迹 = Billboard 印色同心环（贴星点可见辉光外沿，逐环 +0.42 世界单位）；相机 = OrbitControls（环绕 + 推拉 12–300，禁平移）。布局引擎 `universe.ts` 输出 `{x, y, z}` 三通道，2D 首页忽略 z。CSS 假 3D `Planet` 保留为点星后的 HTML 浮层视觉。
> **2026-10-16 sky 3D 同步**：3D 行星贴图改为**沿纬度采样 `STAR_VISUAL.stops`**——与 2D 星球 body 同一条线性渐变单源（木星的橙乳横纹因此天然成为纬度带；旧 `STAR_SURFACE` 纹理带色阶与两极压暗删除）。行星改用**无光照材质**（meshBasic + `toneMapped=false`）贴图原样直出，与 2D CSS 星球逐色一致——试过反照率补偿仍无法一致：只要响应光照，晨昏线照度逐点不同 + ACES 压亮色，贴图必被改写；明暗面/自发光通道下线，亮度层级由色板本身承载（与 2D 同源），能量通道 = 辉光呼吸/闪烁。场景定向光/环境光仅供恒星核（Phong）塑形。自转周期独立为 `STAR_SPIN`（仅剩 period 字段）。
另加**极淡的视角相关边缘暗化**（fresnel：轮廓处 ≈22%、指数 1.8，`onBeforeCompile` 注入 meshBasic，`LIMB_DARK_AMOUNT/POWER` 可调）——中心与主色不动、不响应光照，只为平面渐变找回球体感。
> 另：2D 星球颜色所见即所得，3D 表面却被场景光照再乘一次（定向 1.6 + 环境 0.32，向阳面最高 ≈ ×1.9），亮色板会削顶发白——行星材质以线性反照率标量（`PLANET_ALBEDO ≈ 1/1.5`，universe-scene.tsx）抵消光照增益，向阳面回到渐变原色；分母按观感可调。
> **2026-10-16 sky 3D 同步**：行星贴图改为**沿纬度采样 `STAR_VISUAL.stops`**——与 2D 星球 body 同一条线性渐变单源（木星橙乳横纹因此天然成为纬度带；随机条纹/两极压暗下线，明暗面交还定向光）。原 `STAR_SURFACE` 纹理带色阶删除，仅存自转周期（更名 `STAR_SPIN`）；大气辉光/自发光沿用各档 halo 同源色。改 2D body 渐变时必须同步改 stops，两页才不漂移。

## 3. 七档能量层级（霍金斯校准，2026-10-15）

原 5 底色按霍金斯量表本就单调排序（麻木 < 悲伤 < 恐惧 < 愤怒），唯一缺口是 calm 覆盖了
200–1000 整个上半区。故新增 courage（勇气/主动）与 love（爱/喜悦/平静/开悟）两档，
calm 重新锚定为宽恕·理智——**旧数据 5 值原地有效，零迁移**。颜色沿霍金斯图表色带
（近黑 → 蓝 → 橙棕 → 红 → 金 → 象牙 → 青白；2026-10-16 起按经典太阳系行星色具象化），200 勇气是正负转折点：

| 层级 | 霍金斯带 | 值 | 星体原型 | 基色 | 自发光 | 唤醒度（自转/脉动） |
| --- | --- | --- | --- | --- | --- | --- |
| 羞愧·内疚·冷淡 | 20–75 | `numb` | 黑矮星 | 近黑 `#2a2a38` | 0.03 | 60s 近乎停滞 |
| 悲伤 | 75 | `low` | 深海蓝星 | 深海蓝 `#2296b4`（deepskyblue→darkcyan） | 0.14 | 34s 下沉式呼吸 6s |
| 恐惧·欲望 | 100–125 | `anxious` | 木星 | 木星橙 `#d07f45`（橙乳纹理带） | 0.20 | 6s 不规则闪烁 2.4s |
| 愤怒·骄傲 | 150–175 | `hot` | 赤矮星 | 火砖红 `#c93a1e`（firebrick→orangered） | 0.32 | 9s 日冕呼吸，星点 1.8s 脉冲 |
| 勇气·满意·主动 | 200–310 | `courage` | 熔金太阳 | 琥珀金 `#c98f45`（鲑鱼→金日冕） | 0.38 | 12s 炉火式稳定脉冲 2.6s |
| 宽恕·理智 | 350–500 | `calm` | 月球 | 象牙 `#c8c8c0`（暗面深空蓝 `#226`） | 0.42 | 26s 稳定柔光，无脉动 |
| 爱·喜悦·平静·开悟 | 500–1000 | `love` | 天王星 | 青白 `#8fd8dc`（青→白渐变） | 0.55 | 44s 安静呼吸 5s |

三通道语义随之细化：**色相 = 霍金斯层级位置**（沿图表色带）、**亮度 = 层级**
（单调上升：爱最亮；愤怒响而不亮）、**节奏 = 唤醒度**（自转周期/闪烁，anxious 最急促）。
打标边界规则与 few-shot 见 `lib/yinian/tag.ts`（hot vs courage / courage vs calm / calm vs love）；
扩档后需重跑 `scripts/yinian-tag-sample.mjs` 重建准确率基线。

`prefers-reduced-motion` 下全部动画降级为静态。

## 5. 实现约束

- 星体纯 CSS（线性渐变球面 + 按档位 `box-shadow`，严格参考经典太阳系 CSS；无纹理带/明暗层），无图片资源，无 Canvas/WebGL 依赖
- 星球锚点为被点星点的视口坐标，做边界钳制（压在上半屏，给信笺浮层留位）
- 星点点击热区用 `::after { inset: -10px }` 扩至 ~25px（触屏可用）
- 发布新念头时：打标异步（~11s，POST 秒回），星先隐身等 domain（「此念正在归位……」shimmer 提示；30s 仍未打标按自由星兜底起飞）→ 轮询带回 domain、星进星盘落位，从释念钮飞往落位（约 1.2s，`yn-star-fly` 配 `--fx/--fy` 起跑偏移）→ 到位后星球原地展开浮层
- 星团星系布局（盘面统一倾角、成员星黄金角向日葵落位、盘径公式）另见 `docs/design/yinian-galaxy-layout.md`
- 辉光为 box-shadow（2026-10-16 星环下线，radial.jpeg 环带方案移除）：星点用内 `glow` + 外 `halo` 双层；星球（原地放大）按档位严格照搬参考值——sun 双层金光 `0 0 18px #ffc, 0 0 50px #ffb`、uranus `0 0 10px #b2ffff`、low/hot `0 0 5px` 窄晕、numb 纯 inset 月牙、moon/jupiter 无辉光，配置在 `STAR_VISUAL.shadow`（`yinian-shared.tsx`）
- 二期接入（2026-10-08 落地 U1/U2/U3）：NPC 痕迹原实现为**星点周围的印色同心光环**（`.yn-trace`，每位点评 NPC 一圈、最多三圈，挂在星点 button 内）——**2026-10-16 下线**：评论数在星球浮层的印章位已完整可见，光圈视觉信息重复且干扰星点读感（3D 侧行星痕迹环已于 2026-10-10 先行下线）；星座/漩涡不改星球本身，由布局引擎（`app/yinian/universe.ts`）决定星位——漩涡成员沿黄金角螺旋臂钉住，自由星力导向成簇；漩涡视觉为暗核 + 双臂锥形渐变缓转（`.yn-vortex`）
